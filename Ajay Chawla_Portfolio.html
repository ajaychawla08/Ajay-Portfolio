Log-source health checker

Finds SIEM log sources that have stopped reporting. Reads a SIEM export and an expected-IP list, marks every source OK or No Logs against a time threshold, handles merged-cell blanks and duplicate rows, and exits non-zero so it can run on a schedule.

Stack: Python, CSV/XLSX
Run: python3 checker.py --export … --inventory …

Sigma detections mapped to MITRE ATT&CK

Five rules covering encoded PowerShell, event-log clearing, new local administrators, certutil downloads, and scheduled-task persistence. Each has ATT&CK tags, a severity, known false positives, and a validator script.

Stack: Sigma (YAML), Python
Techniques: T1059.001, T1070.001, T1098, T1105, T1053.005
View on GitHub

IOC enricher

Classifies IPs, domains and hashes, queries VirusTotal and AbuseIPDB, and prints a defanged triage table with a verdict. Includes an offline demo mode that needs no API keys.

Stack: Python (standard library)
Run: python3 enrich.py iocs.txt --offline
